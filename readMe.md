## 🚀 Featured Projects

### [🛣️ Highway Rider --- Self-Driving Highway Car](https://github.com/dhanushnatra/highwayrider)

A highway-driving simulation built with Python, PyTorch, and Pygame,
exploring neural networks and the mathematics behind learning-based
driving decisions.

-   Implemented a neural network from scratch to strengthen
    understanding of the underlying math.
-   Explored calculus and linear algebra in the learning process.
-   Built the driving simulation and game logic with Pygame.
-   Documented the mathematical concepts used in the project.

**Stack:** Python · PyTorch · Pygame · Calculus · Linear Algebra

### [📄 MindStream --- PDF-to-Story Explanations](https://github.com/dhanushnatra/mindStream)

An AI-powered application that turns PDF content into contextual,
story-like explanations.

-   Built a React interface and FastAPI backend.
-   Integrated Retrieval-Augmented Generation (RAG) for context-aware
    responses.
-   Explored AI-generated explanations and audio-oriented learning
    workflows.

**Stack:** React · FastAPI · Ollama · RAG

A desktop application that uses hand gestures to interact with 3D models
in real time.

-   Implemented gesture-based rotation, scaling, and panning.
-   Connected computer-vision input with Three.js rendering.
-   Structured the application into gesture detection, interaction
    logic, and rendering components.

**Stack:** JavaScript · Electron · MediaPipe · OpenCV · Three.js

### [😊 Smiley --- Facial Expression Detection](https://github.com/dhanushnatra/smiley)
